# 🚗 Car Price Prediction

## 📌 Project Overview

Car Price Prediction is a Machine Learning project that predicts the
selling price of a used car based on different features such as
present price, year, kilometers driven, fuel type, seller type,
transmission and owner.

## 🎯 Objective

The main objective of this project is to build a Machine Learning
model that can predict the approximate selling price of a used car.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- Jupyter Notebook
- HTML/CSS

## 📊 Dataset

The dataset contains information about used cars including:

- Year
- Selling Price
- Present Price
- Kms Driven
- Fuel Type
- Seller Type
- Transmission
- Owner

A new feature called **Car Age** was created using the vehicle's year.

## 🔄 Project Workflow

1. Data Collection
2. Data Cleaning
3. Data Preprocessing
4. Feature Engineering
5. Exploratory Data Analysis
6. Model Training
7. Model Evaluation
8. Prediction
9. Flask Deployment

## 🤖 Machine Learning

Regression techniques were used to predict the selling price of
used cars.

The model was trained using processed vehicle data and evaluated
using suitable regression metrics.
